# AGENTS.md

Astro 7 static marketing site for Joaquín López (joalopez.com.ar). No server, no
database, no framework on top of Astro. All user-facing copy/content is **Spanish
(es-AR)** — write new copy in Spanish, not English.

## Commands

```
npm install
npm run dev       # astro dev
npm run build     # astro build -> dist/
npm run preview   # serve dist/
npm run check     # astro check (the only typecheck/lint; no test or lint script exists)
```

There is no test suite and no linter. `npm run check` is the verification step before
finishing. It depends on generated `.astro/types.d.ts`; if types are missing, run
`npx astro sync` first.

## Layout

- `src/consts.ts` — site meta, NAV_LINKS, contact/WhatsApp, `FORM_ACCESS_KEY`.
- `src/data/services.ts` — `ServicePage` type + JSON-LD builders. `src/data/faq.ts` — home FAQ data.
- `src/pages/servicios/*.astro` — each defines a `ServicePage` object and renders `ServiceLayout`.
- `src/content/blog/*.md` + `src/content.config.ts` — blog collection schema (title, description, pubDate required; `draft: true` hides from build, list, and RSS).
- `src/layouts/BaseLayout.astro` — injects Person JSON-LD and page `jsonLd`; `src/components/Seo.astro` — canonical/OG/Twitter tags.
- `src/styles/global.css` — one plain-CSS stylesheet (no Tailwind/CSS-in-JS), imported once in BaseLayout.
- `public/robots.txt`, `public/llms.txt` — **static, hand-maintained, not generated**.

## Gotchas

- `trailingSlash: 'never'` (astro.config.mjs): write internal links **without** a trailing slash.
- New service page: create the `.astro` and also **manually** add it to `public/llms.txt`. Home service cards in `src/components/Services.astro` link to WhatsApp, not to the landing pages.
- Sitemap is generated by `@astrojs/sitemap` (`sitemap-index.xml`), excluding `/gracias`; there is no static sitemap to edit.
- Analytics is opt-in: `PUBLIC_GA_ID` (see `.env.example`, `.env` is gitignored) — empty means no script loads. Conversion events dispatched: `whatsapp`, `email`, `contacto_form`.
- Contact form: empty `FORM_ACCESS_KEY` in `src/consts.ts` makes submit fall back to opening WhatsApp; setting it enables the Web3Forms AJAX flow.
- Deploy host is ambiguous: `docs/deploy.md` says **Vercel** is current, but `netlify.toml` and `public/_headers` (Cloudflare) are also committed. `netlify.toml` pins Node 22. Confirm target host before changing deploy config.
